# DecodeLabs Data Science Internship

## Project 1: Advanced EDA & Feature Engineering

### Dataset Used
Titanic Dataset

### Project Description
As the project did not provide a specific dataset, the Titanic dataset was selected because it is widely used for Exploratory Data Analysis (EDA), missing value handling, outlier detection, and feature engineering.

### Tasks Performed
- Handled missing values using statistical imputation.
- Identified and removed outliers using the IQR method.
- Created new features: FamilySize, IsAlone, and AgeGroup.
- Saved the cleaned dataset.
